# Robot Seed Animation Farm

Bộ dự án Blender tạo phim *Robot nhỏ và hạt mầm cuối cùng* (180 giây / 18 đoạn). Mã nguồn, kịch bản, render pipeline và workflow đang được nhập vào repository này.

Bắt đầu bằng `python3 scripts/pipeline.py doctor` rồi render 2 giây với `python3 scripts/pipeline.py run --chunk 1 --test-frames 30 --preview` sau khi mã nguồn được đưa lên.
